# T-044 기본 가구 재질감·부품 디테일 (scene-engine)

## 1. 한 일
- src/scene/furnitureTexture.ts(신규): 나뭇결(wood)·직물 결(fabric) 회색조 무늬를 캔버스로 그린다. 종류별 한 번만 만들어 공유(128x128 px, dispose 없음). 캔버스가 없으면(jsdom) 그리지 않은 텍스처를 돌려준다(floorTexture와 같은 처리).
- src/scene/partGeometry.ts: 무늬 부품은 UV를 장면 길이(m) 기준 평면 투영으로 만든다(부품 크기와 상관없이 무늬 크기 일정, 나뭇결 0.6 m, 직물 0.1 m). 같은 모양 열쇠(partGeometryKey) 추가.
- src/scene/furnitureTones.ts: 책등 톤 book1~4 추가, materialSpec(roughness/metalness: 손잡이 금속, 천 0.95, 나무 0.7, 민무늬 어두운 다리 0.5/0.15).
- src/scene/furnitureParts.ts: 부품에 grain 필드, partsForKind에 seed(가구 id) 인자 추가. 종류별 디테일:
  - 침대: 발 2개(앞쪽), 도톰한 이불, 이불 윗단 접힌 띠(cream), 더 둥글고 두꺼운 베개
  - 소파: 짧은 다리 4, 등 쿠션(좌석 쿠션 수만큼), 팔걸이 윗면 더 둥글게
  - 의자: 가는 다리 4(둥근 상자, 분할 2), 좌판 널 + 쿠션, 얇고 둥근 등받이
  - 책상: 폭 900 mm 이상(그리고 높이 400 이상)이면 -x쪽 서랍 단(앞면 3 + 손잡이 3) + 반대쪽 다리 2, 미만이면 다리 4만
  - 식탁: 다리 4 + 상판 아래 테 4
  - 옷장: 걸레받이, 문 사이 선, 세로 손잡이(기존 유지)
  - 책장: 칸마다 책 1~3권(폭 3종, 높이 비율 3종, 색 4종). 위치·색은 id 문자열 해시로 정해 같은 입력이면 항상 같다.
  - 상자(kind 없음): 그대로
- src/scene/Furniture.tsx: 가구 단위로 geometry(모양별 공유)와 material(톤+무늬별 공유)을 만들고 가구가 바뀌거나 사라질 때 해제. 경고 상태에서는 무늬(map)를 빼서 경고색이 그대로 보인다. draft는 무늬 유지 + 기존 반투명. 높이 절반 보정은 PartMesh 한 곳 그대로.
- 테스트: furnitureParts.test.ts 보강, furnitureTexture.test.ts 신규.
- 건드리지 않음: probe, 눌림 판정, 이름표, 선택·경고 테두리, 평면 윤곽선, 조명·그림자, 벽·바닥.

## 5. 미해결 질문
- 이전 보고(T-040)에 적힌 그림자 문제는 이번에 손대지 않았다(조명 변경 금지). 가구 부품은 여전히 castShadow를 유지하고 3D 뷰에서 그림자가 보인다. 평면 뷰에는 그림자가 나타나지 않는 것을 스크린샷으로 확인.
- 옷장 문 나뭇결은 가로 방향이다(문은 보통 세로결). 은은해서 그대로 뒀다. 필요하면 세로결 종류를 추가할 수 있다.
- 공유 무늬 텍스처는 dispose하지 않는다(앱 수명 동안 2장). WebGL 컨텍스트 복구는 three가 텍스처를 다시 올린다.
