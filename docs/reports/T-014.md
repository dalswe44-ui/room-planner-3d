# T-014 보고 (furniture-placement): 가구 추가 흐름 개선

## 1. 한 일 (src/furniture/)
- 기본 가구 버튼(`preset-<kind>`)을 누르면 빈 자리에 바로 추가되고 선택됨(이름은 종류 이름, 치수는 기본값). 폼 채우기, presetKind, aria-pressed, `preset-box` 버튼 삭제. 직접 입력 폼(`aria-label="직접 입력"`)은 그대로, 이름으로 종류 짐작.
- 새 `findFreeSpot(size, room, others)`: 방 가운데에서 100 mm 격자로 바깥을 훑어 겹치지 않고 방 안에 드는 가장 가까운 자리(같은 거리면 위쪽, 왼쪽), 변은 10 mm 격자. 방보다 크거나 빈 자리가 없으면 가운데. 두 추가 흐름 모두 적용.
- 목록에서 이름과 종류가 같으면 종류를 다시 보이지 않음. contracts의 KIND_LABEL·limits 사용(자체 정의와 캐스트 삭제). usePlacement 주석 "100 mm" → SNAP_MM. 장면·목록 클릭으로 선택이 바뀌면 편집 칸 scrollIntoView.
- 테스트: 바뀐 동작에 맞춰 4개 수정(이유 기록), 새 테스트 다수(findFreeSpot 7건 포함).
