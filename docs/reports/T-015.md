# T-015 보고 (room-input): 자동 저장, 사진 저장, 배치도 가져오기 개선

## 1. 한 일
- 새 src/persistence/: `savedProject.ts`(형식 {format:'room-planner-project', version:1, project}, `parseSavedProject` 경계 검사: 형식·버전·단위·천장·꼭짓점(정수, 3개 이상, 음수 불가)·방 폭 범위·개구부·가구 필드와 치수. 방 밖 가구는 허용), `usePersistence.ts`(프로젝트가 바뀔 때만 300 ms 뒤 localStorage `room-planner-3d/project`에 저장, pagehide·visibilitychange에 밀린 저장 마무리, 모든 접근 try/catch, 불러오기는 되돌리기 기록에 넣지 않음), `photoBlob.ts`(idb-keyval, 키 `room-planner-3d/photo`). 테스트.

- RoomPanel: limits.ts 사용.
