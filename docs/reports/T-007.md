## 1. 한 일 (src/photo/ 새 파일)
- `parseLayoutImport.ts`: `parseLayoutImport(text, {displayUnit, ceilingHeight})` → `{ok:true, project, warnings, notes}` | `{ok:false, errors}`. 첫 `{`부터 마지막 `}`까지만 읽음. 숫자 변환은 `lengthToMm`. 범위 방 500~20000, 천장 1800~5000, 가구 10~10000 mm. 회전 90·270이면 중심 left + d/2, top + w/2. 위치 없으면 방 가운데 + 경고. h null이면 600 mm + 경고. 방 밖은 경고만. rotationDeg가 0·90·180·270이 아니면 거부.
- `photoStore.ts`: 사진을 object URL로 메모리에만. 교체·삭제 시 URL 해제.
- `PhotoPanel.tsx`, `photo.css`, `index.ts`: 사진 첨부·지우기, 문구 복사(실패 시 읽기 전용 textarea 전체 선택), 사용 순서 3줄, JSON 붙여넣기·.json 파일, 오류, 미리보기(방 크기, 가구, AI notes, warnings), 인라인 확인 뒤 `replaceProject`, 성공 문구.
