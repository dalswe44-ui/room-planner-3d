# T-006 보고 (scene-engine, 결함 D-T005-01)

평면 뷰에서 가구 이름이 상자 위에 글자로 보이도록 고쳤다. 에이전트가 최종 응답으로 돌려준 내용을 헤드가 요약 저장.

## 변경 파일 (src/scene/)
- `Furniture.tsx`: `FurnitureBox`에 `showLabel`, 상자 메시 안에 `FurnitureLabel`(drei `Html`, DOM 글자).
- `SceneView.tsx`: `showLabel={viewMode === '2d'}`. 3D 뷰에는 이름표 없음.
- `scene.css`: `.furniture-label-wrap`, `.furniture-label`, `.scene-root`에 `isolation: isolate`.

## 방법
- `Html`에 portal을 주지 않아 글자가 `scene-canvas` 안에 붙는다. 위치는 상자 윗면 가운데.
- 외부 폰트·drei `Text`·의존성 추가 없음.
- `pointerEvents="none"`과 CSS로 글자가 포인터를 받지 않음. 이름표 위 점의 `elementFromPoint`가 `CANVAS`, 그 점에서 끌기 3번 모두 성공.
- 말줄임: 최대 너비 = 화면상 상자 폭 − 4 px(최소 56 px), `useFrame`에서 DOM 스타일로 갱신.
- `frameloop="demand"`: 이름표가 붙을 때 `invalidate()` 한 번.
- `zIndexRange={[10, 0]}`와 `isolation: isolate`로 이름표가 장면 밖 UI 위로 올라가지 않음.
- `__sceneProbe`와 레이캐스트에 영향 없음(Html은 Group).
