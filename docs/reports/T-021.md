# T-021 보고 (scene-engine): 끄는 지점의 화면 1 px = 바닥 mm 전달

## 한 일 (src/scene/)
- `pointer.ts`: 순수 함수 `mmPerPxAt(camera, rect, clientX, clientY)` — (x,y), (x+1,y), (x,y+1)을 바닥으로 투영해 두 거리 평균(실수 mm, 반올림 안 함). 바닥과 안 만나거나 유한하지 않거나 0 이하면 undefined.
- `gestures.ts`: deps에 선택 항목 `mmPerPxAt`, 가구를 끄는 move에서만 호출해 `onFloorPointerMove(floor, mmPerPx)`로 전달.
- `SceneView.tsx`: 현재 카메라·캔버스 rect에 연결.
- 테스트: 평면 뷰는 위치 무관·zoom 2배면 절반, 원근은 먼 곳이 큼, 바닥과 안 만나면 undefined, 전달·미전달.

## 검증
typecheck·lint 통과, src/scene 70개. Playwright(dev 서버) 1280×800 평면 뷰 기본 배율 mmPerPx ≈ 5.126(100 mm ≈ 19.5 px와 일치), 휠 확대 후 ≈ 4.870.

## 못 한 것
3D 뷰 값은 단위 테스트만. 실기기 미확인. build·e2e는 헤드가 통합 때.
