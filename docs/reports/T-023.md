# T-023 보고 (scene-engine): 장면을 도면 모양으로, 도구 막대 자리

## 1. 한 일 (src/scene/)
수정: SceneView.tsx, Room.tsx, Furniture.tsx, CameraRig.tsx, camera.ts, geometry.ts, sceneProbe.ts, scene.css. 신규: SceneOverlays.tsx, overlayMath.ts, floorTexture.ts와 테스트 2개.
- **도구 막대 자리(selectionOverlay)**: scene-root 안 절대 위치 div를 ref.style.transform으로 옮김(drei Html 미사용, T-018 함정 없음). useFrame(카메라)과 layout effect(가구·단위·선택·뷰)에서 갱신, frameloop demand 유지. 가구 화면 경계 위 가운데 8px, 자리가 없으면 아래, 장면 안으로 가둠. 선택이 없거나 끄는 중이면 DOM에서 뺌. 감싸는 층 pointer-events none, 막대만 auto. 막대 위에서 누른 것은 끌기·빈 곳 탭으로 처리하지 않음. role="img"를 Canvas 안쪽 층으로 옮김(막대 버튼이 접근성 트리에 남도록).
- **벽 거리 치수선(wallDistances)**: 평면 뷰 전용. 먹색 1px 선과 눈금, 글자 `scene-dist-0..3`(.num, 현재 단위 숫자). 음수는 경고색. 거리 0은 선 없이 글자만. 끄는 중 실시간.
- **평면 뷰**: 배경 #eef1f0. 바닥은 코드로 그린 참나무 널 CanvasTexture(바탕 #e2cfae, 널 150×1200 mm, 엇갈림, 밝기 ±3%, 결정적 난수, 실제 mm 크기로 반복). 벽 윗면 먹색. 방 치수선(위쪽 폭, 왼쪽 깊이, `room-dim-width`/`room-dim-depth`, "3600 mm"). 카메라 여백 왼 60·위 52·오른 16·아래 16 px. 가구 부품에 옅은 먹선. 선택은 줄자 노랑 3px 아래 먹색 6px(화면 픽셀 굵기). 경고는 고유색에 경고색 65% + 빨간 테두리. 이름표는 반투명 종이색 바탕.
- **3D 뷰**: 벽 안쪽 #f4f2ec, 바깥 #e4e0d6, 윗면 먹색. 반구광 + 주광, 그림자는 3D에서만(지도 1024, demand). Canvas flat(톤 매핑 없음). 안티에일리어싱·dpr [1,2] 확인. 안내 문구 두 문장.
- 지킨 것: probe·floorToClient·끌기·mmPerPx·이름표 회귀(T-018)·testid.
