# T-024 보고 (furniture-placement): 선택한 가구의 도구 막대와 패널 다듬기

## 1. 한 일 (src/furniture/)
- 새 `ItemToolbar.tsx`: 먹색 알약 막대, 흰 아이콘 버튼 4개(44×44, aria-label·title). 복제(tool-duplicate), 왼쪽 돌리기(tool-rotate-left, +90), 오른쪽 돌리기(tool-rotate-right, −90), 삭제(tool-delete, 확인 없음). role="toolbar", data-testid="item-toolbar". 선택 없으면 null. pointerdown 전파 차단. 삭제 아이콘은 어두운 막대 위 대비를 위해 --warn과 흰색을 섞음.
- 새 `duplicateItem.ts`: 이름·종류·치수·색·회전 그대로, 원본에서 가장 가까운 빈 자리에 addItem 한 번(되돌리기 한 번, 복제본 선택).
- `placement.ts`: `findFreeSpot(size, room, others, from?)` 시작점 인자(기본은 방 가운데).
- 새 `useSelectedWallDistances.ts`: 끄는 중이면 임시 위치. 패널도 이 훅 사용.
- `FurniturePanel.tsx`, `furniture.css`: 선택한 가구 칸을 카드로(색 견본, 이름, "1200 × 600 × 720 mm" 요약, 아이콘 동작 줄, 경고, 편집 칸, 벽 거리). 기본 가구는 칩, 추가는 노랑 버튼(먹색 글자), 목록 줄 선택 시 연노랑 바탕과 노랑 띠. 하드코딩 파랑 제거.
- 테스트: ItemToolbar 12건, findFreeSpot 시작점 4건 등 25건 추가. 기존 테스트 수정 없음.

## 2. 실행 결과
typecheck·lint·build 통과, src/furniture 131개 통과. Playwright 1280×800, 390×780 캡처를 직접 확인(정렬·잘림 없음, 도구 막대 버튼 44×44).

## 3. 완료 기준과 차이
충족. 차이 하나: 패널에 `item-rotate-left`를 만들지 않고 `item-rotate-right`를 추가.

## 4. 변경 요청과 헤드 처리
- **헤드의 계약 오류를 에이전트가 찾음**: CONTRACT에 `item-rotate`를 "시계 90도"라고 적었으나 SPEC P-4·기존 테스트·e2e는 반시계 +90. 에이전트가 코드와 SPEC을 따르고 보고 → 헤드가 CONTRACT를 고침(`item-rotate` = 반시계, 패널에 `item-rotate-right` 추가).
- 조립 코드 → 헤드가 T-023 뒤에 반영.
- 헤더 넘침 → 이미 수정(T-025 후속).
- 입력 칸마다 오류 줄 자리가 잡혀 간격이 넓다 → T-002c의 의도된 절충(버튼 밀림 방지). 유지.

## 5. 미해결
복제는 100 mm 격자 탐색이라 원본과 딱 붙지 않을 수 있음. 빈 자리가 없으면 원본 자리에 겹쳐 놓이고 경고.
