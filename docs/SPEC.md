# SPEC — 3D 가구배치 1차 버전 (T-002 ~ T-005)

길이는 전부 mm이고 구현 방법은 정하지 않는다. 단위·좌표 규약은 CLAUDE.md, 식별자와 조회 함수는 docs/CONTRACT.md가 원본이다. **(확인)** = 헤드가 임시로 정한 값(사용자 확인 필요). **(제안)** = spec-report가 빈 곳을 메운 것(헤드 확인 필요). "반영"은 앱의 값이 바뀌는 것이고, 브라우저에 보관하는 "저장"은 5절의 다음 작업이다.

## 1. 사용자 흐름
① 방 치수 입력(폭·깊이·천장 높이를 mm·cm·m 중 편한 단위로, 언제든 수정) → ② 평면 뷰(위에서 본 화면)와 3D 뷰로 확인 → ③ 가구 치수 입력(이름, 폭·깊이·높이)으로 상자 가구 추가 → ④ 배치(평면 뷰에서 끌기, 90도 회전, 겹침·방 이탈 경고와 벽까지 거리로 들어가는지 판단) → ⑤ 저장(5절. 이번 버전은 새로 고치면 기본 방으로 돌아간다).

## 2. 기능과 동작 규칙
- **방**: 직사각형. 기본값 폭 3600 × 깊이 3000 × 천장 높이 2400 (확인). 허용 범위는 폭·깊이 500 ~ 20000, 천장 높이 1800 ~ 5000이고 경계값은 허용한다 (확인). 범위 밖, 빈 값, 0, 음수, 글자는 반영하지 않고 그 칸에 오류 문구를 보여 준다 (확인). 오류 문구에는 허용 범위가 현재 표시 단위로 들어간다 (제안).
- **단위 확인 경고**: 반영된 폭이나 깊이가 1000 미만이거나 15000 초과이면 값은 반영하되 "단위를 확인하세요"가 들어간 경고를 띄운다 (확인). 천장 높이는 대상이 아니다.
- **단위**: 표시 단위 mm·cm·m 전환은 화면 표시만 바꾸고 값(정수 mm)은 바꾸지 않는다. 숫자만 넣으면 현재 표시 단위로, "120cm"·"1.2m"처럼 단위를 붙이면 그 단위로 읽어 가장 가까운 mm로 맞춘다. 방과 가구의 모든 길이 칸이 같다.
- **가구**: 이름, 폭(w)·깊이(d)·높이(h), 색을 가진 상자. 폭·깊이·높이는 10 ~ 10000이고 (확인) 거부 규칙은 방과 같다. 색은 추가할 때 자동으로 정해지고, 이름을 비우면 "가구"가 된다 (제안). 추가한 뒤에도 이름·치수·색을 고치고 삭제할 수 있다. 새 가구는 방 가운데에 회전 0으로 놓이고 선택된다 (확인). 방보다 큰 가구도 범위 안이면 추가된다. 목록의 줄이나 화면의 가구를 누르면 그 가구 하나가 선택되고, 빈 곳을 짧게 누르면 풀린다.
- **끌기**: 평면 뷰와 3D 뷰에서 동작한다(3D 뷰의 끌기는 완료 기준이 아니다). 잡은 지점이 포인터를 따라가고 끄는 동안 카메라는 멈춘다. 손을 뗄 때 바닥 사각형(회전 반영)의 왼쪽 변(x가 작은 쪽)과 위쪽 변(z가 작은 쪽)이 가장 가까운 10의 배수에 맞춰 확정되고 (확인), 움직이지 않고 떼면 그대로다 (제안). 변을 기준으로 맞추는 것은 폭 450 같은 가구도 벽에 딱 붙일 수 있게 하기 위해서다.
- **자석 맞춤** (2026-11-17 사용자 요청. 거리는 사용자 결정 08:32: 화면 기준): 끄는 동안 바닥 사각형의 변이 벽이나 다른 가구의 반대쪽 변에, 끄는 지점에서 화면 12 px에 해당하는 바닥 거리 이내로 오면 그 변에 딱 붙는다(확대하면 좁아지고 축소하면 넓어진다. 평면 뷰 기본 배율 1280×800에서 약 62 mm. 장면이 배율을 넘기지 못하면 20 mm). 다른 가구는 다른 축에서 겹치거나 같은 거리 이내일 때만. 붙은 축에는 10 mm 격자를 적용하지 않는다. 맞닿은 가구는 겹침 경고가 없다.
  - **M-1** 1000×600 가구의 왼쪽 변을 왼쪽 벽에서 자석 거리의 절반 앞에 놓음 → 왼쪽 변이 0 (center.x 500). 이 거리는 20 mm보다 크다.
  - **M-2** 다른 가구를 그 오른쪽 자석 거리의 절반 옆에 놓음 → 맞닿고 둘 다 warning false.
  - **M-3** 자석 거리의 두 배 간격으로 놓음 → 붙지 않는다.
- **방향키 이동** (2026-11-17 사용자 요청): 가구를 선택한 상태에서 방향키로 10 mm, Shift+방향키로 1 mm 움직인다(평면 뷰 기준 → +x, ↓ +z). 자석·격자는 적용하지 않는다. 입력 칸에 포커스가 있으면 동작하지 않는다.
  - **K-1** 책상 선택 후 → 3번 → center.x +30. Shift+↓ 2번 → center.z +2. 이름 칸에 포커스를 두고 → → 그대로.
- **회전**: 버튼 한 번에 반시계 90도(0 → 90 → 180 → 270 → 0) (확인). 중심과 w·d·h는 그대로이고 바닥 사각형이 돈다.
- **겹침**: 두 가구의 바닥 사각형이 x·z 두 방향 모두 1 이상 겹칠 때. 변이 정확히 맞닿은 것은 겹침이 아니다 (확인).
- **방 이탈**: 바닥 사각형의 일부가 방 경계 밖으로 1 이상 나갈 때. 벽에 정확히 붙은 것은 이탈이 아니다 (확인). 방을 줄여 가구가 밖에 놓이면 가구 위치는 그대로 두고 이탈로 표시한다 (확인).
- **경고 표시**: 겹침과 이탈은 높이를 따지지 않고, 막지 않으며, 해당 가구를 경고 색으로 그리고 선택한 가구에는 문구로 알린다 (확인). 문구에는 겹침이면 "겹침", 이탈이면 "방 밖"이 들어간다 (제안). 끄는 동안에도 임시 위치 기준으로 바뀐다.
- **벽까지 거리**: 선택한 가구의 바닥 사각형(회전 반영)에서 네 벽(벽 0 ~ 3, CONTRACT 3절)까지의 거리 4개를 현재 표시 단위로 보여 준다 (확인). 벽 밖으로 나간 쪽은 음수다 (제안).
- **뷰와 배포**: 평면 뷰와 3D 뷰는 같은 데이터를 그리고 처음에 방 전체가 보인다 (제안). 공개 URL은 로그인 없이 열린다.

## 3. 범위 밖
- 사진에서 방 구조나 치수를 자동으로 뽑는 기능은 만들지 않는다. 사진은 참고 이미지이고 치수의 근거는 입력값뿐이다.
- 직사각형이 아닌 방, 문·창, 벽 스냅, 통로·여유 공간 경고, 90도 단위가 아닌 회전, 가구 쌓기, 가구와 천장 높이의 비교, 3D 모델·카탈로그 가구, JSON 가져오기, 로그인·서버, 공유 링크, 홈 화면 설치, 겹침·이탈 배치를 막는 동작.

## 4. 완료 기준 체크리스트

### 4-2. 2026-11-17 추가 기능 (사용자 요청과 pstack 점검 반영, 헤드 작성)
기준 방은 3600 / 3000 / 2400. 새 가구는 빈 자리에 놓인다(방 가운데에서 가장 가까운, 겹치지 않는 자리).
- **B-1** `preset-desk`를 누름 → 가구 1개가 바로 추가되고 선택된다. probe의 kind `desk`, size w 1200 / h 720 / d 600.
- **B-2** 방을 6000 / 3000으로 바꾸고 기본 가구 7개 버튼을 차례로 누름 → 7개 모두 warning false, 마지막(식탁)만 선택.
- **L-1** 사진·배치도 탭에서 `docs/evidence/layout-reader/sample-result.md`의 JSON을 붙여 넣고 적용 → probe.room 3400 / 2800 / 2400, 침대 중심 (500, 1000), 책상 (2800, 500), 옷장 (1750, 2500), 옷장 높이 2000(높이가 없어 종류 기본값).
