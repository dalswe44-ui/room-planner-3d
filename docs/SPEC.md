# SPEC — 3D 가구배치 1차 버전 (T-002 ~ T-005)

길이는 전부 mm이고 구현 방법은 정하지 않는다. 단위·좌표 규약은 CLAUDE.md, 식별자와 조회 함수는 docs/CONTRACT.md가 원본이다. **(확인)** = 헤드가 임시로 정한 값(사용자 확인 필요). **(제안)** = spec-report가 빈 곳을 메운 것(헤드 확인 필요). "반영"은 앱의 값이 바뀌는 것이고, 브라우저에 보관하는 "저장"은 5절의 다음 작업이다.

## 1. 사용자 흐름
① 방 치수 입력(폭·깊이·천장 높이를 mm·cm·m 중 편한 단위로, 언제든 수정) → ② 평면 뷰(위에서 본 화면)와 3D 뷰로 확인 → ③ 가구 치수 입력(이름, 폭·깊이·높이)으로 상자 가구 추가 → ④ 배치(평면 뷰에서 끌기, 90도 회전, 겹침·방 이탈 경고와 벽까지 거리로 들어가는지 판단) → ⑤ 저장(5절. 이번 버전은 새로 고치면 기본 방으로 돌아간다).

## 2. 기능과 동작 규칙
- **방**: 직사각형. 기본값 폭 3600 × 깊이 3000 × 천장 높이 2400 (확인). 허용 범위는 폭·깊이 500 ~ 20000, 천장 높이 1800 ~ 5000이고 경계값은 허용한다 (확인). 범위 밖, 빈 값, 0, 음수, 글자는 반영하지 않고 그 칸에 오류 문구를 보여 준다 (확인). 오류 문구에는 허용 범위가 현재 표시 단위로 들어간다 (제안).
- **단위 확인 경고**: 반영된 폭이나 깊이가 1000 미만이거나 15000 초과이면 값은 반영하되 "단위를 확인하세요"가 들어간 경고를 띄운다 (확인). 천장 높이는 대상이 아니다.
- **단위**: 표시 단위 mm·cm·m 전환은 화면 표시만 바꾸고 값(정수 mm)은 바꾸지 않는다. 숫자만 넣으면 현재 표시 단위로, "120cm"·"1.2m"처럼 단위를 붙이면 그 단위로 읽어 가장 가까운 mm로 맞춘다. 방과 가구의 모든 길이 칸이 같다.
- **가구**: 이름, 폭(w)·깊이(d)·높이(h), 색을 가진 상자. 폭·깊이·높이는 10 ~ 10000이고 (확인) 거부 규칙은 방과 같다. 색은 추가할 때 자동으로 정해지고, 이름을 비우면 "가구"가 된다 (제안). 추가한 뒤에도 이름·치수·색을 고치고 삭제할 수 있다. 새 가구는 방 가운데에 회전 0으로 놓이고 선택된다 (확인). 방보다 큰 가구도 범위 안이면 추가된다. 목록의 줄이나 화면의 가구를 누르면 그 가구 하나가 선택되고, 빈 곳을 짧게 누르면 풀린다.
- **끌기**: 평면 뷰와 3D 뷰에서 동작한다(3D 뷰의 끌기는 완료 기준이 아니다). 잡은 지점이 포인터를 따라가고 끄는 동안 카메라는 멈춘다. 손을 뗄 때 바닥 사각형(회전 반영)의 왼쪽 변(x가 작은 쪽)과 위쪽 변(z가 작은 쪽)이 가장 가까운 10의 배수에 맞춰 확정되고 (확인), 움직이지 않고 떼면 그대로다 (제안). 변을 기준으로 맞추는 것은 폭 450 같은 가구도 벽에 딱 붙일 수 있게 하기 위해서다.
- **자석 맞춤** (2026-11-17 사용자 요청, 거리 2 cm는 사용자 결정 00:43): 끄는 동안 바닥 사각형의 변이 벽이나 다른 가구의 반대쪽 변에 20 mm 이내로 오면 그 변에 딱 붙는다(다른 가구는 다른 축에서 겹치거나 20 mm 이내일 때만). 붙은 축에는 10 mm 격자를 적용하지 않는다. 맞닿은 가구는 겹침 경고가 없다.
  - **M-1** 1000×600 가구의 왼쪽 변을 왼쪽 벽 15 mm 앞까지 끌어 놓음 → 왼쪽 변이 0 (center.x 500).
  - **M-2** 다른 가구를 그 오른쪽 15 mm 옆까지 끌어 놓음 → 맞닿고 둘 다 warning false.
  - **M-3** 30 mm 간격으로 놓음 → 붙지 않는다.
- **회전**: 버튼 한 번에 반시계 90도(0 → 90 → 180 → 270 → 0) (확인). 중심과 w·d·h는 그대로이고 바닥 사각형이 돈다.
- **겹침**: 두 가구의 바닥 사각형이 x·z 두 방향 모두 1 이상 겹칠 때. 변이 정확히 맞닿은 것은 겹침이 아니다 (확인).
- **방 이탈**: 바닥 사각형의 일부가 방 경계 밖으로 1 이상 나갈 때. 벽에 정확히 붙은 것은 이탈이 아니다 (확인). 방을 줄여 가구가 밖에 놓이면 가구 위치는 그대로 두고 이탈로 표시한다 (확인).
- **경고 표시**: 겹침과 이탈은 높이를 따지지 않고, 막지 않으며, 해당 가구를 경고 색으로 그리고 선택한 가구에는 문구로 알린다 (확인). 문구에는 겹침이면 "겹침", 이탈이면 "방 밖"이 들어간다 (제안). 끄는 동안에도 임시 위치 기준으로 바뀐다.
- **벽까지 거리**: 선택한 가구의 바닥 사각형(회전 반영)에서 네 벽(벽 0 ~ 3, CONTRACT 3절)까지의 거리 4개를 현재 표시 단위로 보여 준다 (확인). 벽 밖으로 나간 쪽은 음수다 (제안).
- **뷰와 배포**: 평면 뷰와 3D 뷰는 같은 데이터를 그리고 처음에 방 전체가 보인다 (제안). 공개 URL은 로그인 없이 열린다.

## 3. 범위 밖
- 사진에서 방 구조나 치수를 자동으로 뽑는 기능은 만들지 않는다. 사진은 참고 이미지이고 치수의 근거는 입력값뿐이다.
- 직사각형이 아닌 방, 문·창, 벽 스냅, 통로·여유 공간 경고, 90도 단위가 아닌 회전, 가구 쌓기, 가구와 천장 높이의 비교, 3D 모델·카탈로그 가구, JSON 가져오기, 로그인·서버, 공유 링크, 홈 화면 설치, 겹침·이탈 배치를 막는 동작.

## 4. 완료 기준 체크리스트
형식은 `조작 → 기대 결과`. 따로 적지 않으면 **기본 상태**(새로 연 직후: 방 3600 / 3000 / 2400, 가구 없음, 단위 mm, 평면 뷰)에서 시작한다. **probe** = `window.__sceneProbe.snapshot()`의 값(실제로 그려진 것). **입력** = 칸에 값을 넣고 Enter. **거부** = probe 값이 그대로이고 그 칸의 `<testId>-error`가 보임. **추가** = `furniture-name`·`furniture-w`·`furniture-d`·`furniture-h` 칸에 이름·폭·깊이·높이를 넣고 `furniture-add`. **A** = 1000·600·700, **B** = 1000·1000·500으로 추가한 가구. **근처** = 목표 점에서 각 축 "화면 1픽셀의 길이 + 5" 이내. **†** = CONTRACT 8절에 식별자가 아직 없는 요소.

- **R-1** 기본 상태 → probe.room과 `room-width`·`room-depth`·`room-height` 칸이 3600 / 3000 / 2400, 오류·경고 없음.
- **R-2** `room-width`에 빈 값, 0, -100, abc, 1m20cm을 차례로 입력 → 매번 거부. 이어서 4000 입력 → 4000, 오류 없음.
- **R-3** `room-width`에 499, 20001 입력 → 거부. 500, 20000 입력 → 반영. `room-depth`도 같다. `room-height`는 1799, 5001이 거부, 1800, 5000이 반영이고 `room-unit-warning`은 뜨지 않는다.
- **R-4** 단위 mm에서 `room-width`에 3.5 입력(m로 생각한 값) → 거부되고 오류 문구에 500과 20000이 있다.
- **R-5** `room-width`에 999, 1000, 15000, 15001을 차례로 입력 → 넷 다 반영되고, 999와 15001일 때만 "단위를 확인하세요"가 들어간 `room-unit-warning`이 보인다. `room-depth`도 같다.
- **U-1** `unit-cm`, `unit-m`, `unit-mm`을 차례로 누름 → 누른 버튼만 `aria-pressed="true"`, 방 칸이 360.0 / 300.0 / 240.0 → 3.600 / 3.000 / 2.400 → 3600 / 3000 / 2400, probe.room은 그대로다.
- **U-2** (왕복) `room-width` 1234 입력, A 추가, 단위를 mm → cm → m → mm로 바꾸며 매번 `room-width` 칸에서 고치지 않고 Enter → 칸은 1234 → 123.4 → 1.234 → 1234, probe.room과 A의 center·size는 매번 그대로, 오류 없음.
- **U-3** 단위 cm에서 `room-width`에 420 입력 → probe 4200. 단위 m에서 4.3 입력 → 4300. 단위 mm에서 440cm, 4.5m, " 4.6 M " 입력 → 4400, 4500, 4600.
- **U-4** 단위 m에서 `room-width`에 3600 입력(mm로 생각한 값) → 거부.
- **F-1** 책상·1200·600·720으로 추가 → `item-row` 1개, probe의 그 가구는 size w 1200·h 720·d 600, center x 1800·y 360·z 1500, rotationDeg 0, selected true, warning false.
- **F-2** 나머지 칸은 A의 값으로 두고 `furniture-w`에 빈 값, 0, -5, abc, 9, 10001을 차례로 넣어 매번 `furniture-add` → 매번 `item-row` 수가 그대로이고 `furniture-w-error`가 보인다. `furniture-d`, `furniture-h`도 같다. 10, 10000은 추가된다.
- **F-3** 단위 mm에서 폭 0.6(m로 생각한 값)으로 추가 → 오류, 추가 안 됨. 단위 cm에서 120·60·72로 추가 → F-1과 같은 size.
- **F-4** A의 폭·깊이·높이 칸†에 1400, 800, 900 입력 → probe size w 1400·h 900·d 800, center.x·z는 그대로, center.y 450. 이어서 폭 칸†에 0, 10001, abc 입력 → 매번 거부.
- **F-5** A의 이름 칸†을 소파로, 색†을 다른 색으로 → `item-row`에 소파, 화면의 상자 색이 바뀐다(색은 화면 확인). 이름을 비우고 추가 → `item-row`에 "가구".
- **F-6** A, B 추가 후 A의 `item-row`를 누름 → A만 selected true. 빈 바닥을 짧게 누름 → 모두 false. 다시 A를 선택하고 `item-delete` → `item-row` 1개, probe.items에 B만 남는다.
- **P-1** 평면 뷰에서 A의 중심을 눌러 (1000, 800)으로 끌어 놓음 → center.x·z가 (1000, 800) 근처, size·rotationDeg는 그대로, 끌기 전후의 `floorToClient(0, 0)`이 같다.
- **P-2** 이어서 (2456, 1994), (707, 2213)으로 차례로 끌어 놓음 → 놓을 때마다 center.x·z가 모두 10의 배수(A는 폭과 깊이의 절반이 10의 배수라 변과 중심이 함께 맞는다). 이어서 450·450·800 가구를 추가해 (500, 500) 근처로 끌어 놓음 → center.x - 225와 center.z - 225가 10의 배수.
- **P-3** A의 중심에서 (+300, +200) 떨어진 점을 잡아 x로 +500, z로 +300 끌어 놓음 → center가 (2300, 1800) 근처.
- **P-4** 선택을 푼 뒤 A를 누르고 움직이지 않은 채 뗌 → selected true, center는 (1800, 1500) 그대로. 이어서 `item-rotate`를 네 번 누름 → rotationDeg 90 → 180 → 270 → 0, center·size는 그대로.
- **W-1** B를 두 번 추가(둘 다 방 가운데) → 둘 다 warning true, `item-status`에 "겹침".
- **W-2** 이어서 하나를 (650, 650)으로 끌어 놓음(변이 벽과 다른 가구에서 150 mm라 자석에 붙지 않음) → 둘 다 warning false, `item-status` 요소가 없다. 다시 (1800, 1500)으로 끌어 놓음 → 그 근처에 놓이고(막지 않음) 둘 다 warning true.
- **W-3** (맞닿음) B 추가 → `room-width` 5600 입력 → B를 한 번 더 추가(x 1300 ~ 2300과 2300 ~ 3300) → 둘 다 warning false. 이어서 둘째 가구의 폭 칸†에 1002 입력 → 둘 다 warning true.
- **W-4** (벽에 붙음, 방보다 큰 가구) 3600·3000·500으로 추가 → warning false. 이어서 폭 칸†에 3602 입력 → 반영되고 warning true, `item-status`에 "방 밖". 폭 4000 가구를 새로 추가해도 추가되고 warning true.
- **W-5** (방 줄이기) B 추가 후 `room-width` 2300, 2299, 3600 입력 → warning false → true → false, center.x 불변.
- **W-6** A를 (100, 1500)으로 끌어 놓음 → 그 근처에 놓이고 warning true, `item-status`에 "방 밖".
- **W-7** W-1에 이어 `room-width` 2000 입력 → 선택한 가구의 `item-status`에 "겹침"과 "방 밖"이 둘 다 있다.
- **D-1** A 추가 → 벽 0·1·2·3까지의 거리†가 1200, 1300, 1200, 1300. `unit-cm` → 120.0, 130.0, 120.0, 130.0. `unit-m` → 1.200, 1.300, 1.200, 1.300. 단위 mm로 돌아와 `item-rotate` 한 번 → 1000, 1500, 1000, 1500.
- **D-2** A를 (1000, 800)으로 끌어 놓음 → 거리† 4개가 probe의 room·center·size로 계산한 값과 같다.
- **D-3** 3600·3000·500으로 추가 → 거리† 넷 다 0. 폭 칸†에 3700 입력 → 벽 1·3이 -50. 선택을 풂 → 거리† 없음.
- **V-1** `view-3d`, `view-2d`를 차례로 누름 → probe.view가 2d → 3d → 2d, 누른 버튼만 `aria-pressed="true"`.
- **V-2** 방을 4200 / 2800 / 2300으로 입력하고 A 추가 후 두 뷰를 오감 → 두 뷰 모두 probe.room이 4200 / 2800 / 2300이고 가구 값(center, size, rotationDeg, warning)이 서로 같다.
- **V-3** 기본 상태의 `floorToClient` → 평면 뷰에서 (3600, 0)은 (0, 0)의 오른쪽 같은 높이, (0, 3000)은 (0, 0)의 아래 같은 가로 위치다. 평면 뷰와 3D 뷰 모두 방 네 모서리가 `scene-canvas` 영역 안이다.
- **V-4** W-1 상태의 3D 뷰(화면 확인) → 바닥·벽·상자가 보이고 카메라 쪽 벽이 방 안을 가리지 않으며 겹친 가구는 경고 색.
- **X-1** 공개 URL을 로그인·쿠키 없는 새 창에서 엶 → 로그인 요구 없이 `scene-canvas`와 `room-width`가 보인다.
