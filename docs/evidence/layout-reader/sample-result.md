# 배치도 읽기 프롬프트 시험 1 (헤드, 2026-11-17)

- 그림: `sample-handdrawn.jpg`. 헤드가 손그림처럼 흔들린 선으로 만든 시험 그림(실제 사용자 그림 아님). 방 340×280 cm, 침대·책상·옷장.
- 읽은 것: 헤드(Claude)가 LAYOUT_READER_PROMPT를 따라 직접 읽음.

## 1차 프롬프트(규칙 6개)로 읽었을 때 드러난 문제
"숫자로 적힌 값만" 규칙 때문에, 벽에 붙어 그려졌지만 0이 적혀 있지 않은 침대(왼쪽·위쪽), 책상(오른쪽), 옷장(아래쪽)의 위치가 null이 된다. 손그림에서는 벽에 붙은 가구에 0을 적지 않는 경우가 대부분이다.
→ 규칙 5(벽선에 붙어 그려지면 0)와 규칙 6(치수선이 애매하면 그럴듯한 해석 + notes)을 더했다.

## 2차 프롬프트로 읽은 결과
```json
{
  "format": "room-layout",
  "version": 1,
  "unit": "cm",
  "room": { "width": 340, "depth": 280, "height": 240 },
  "items": [
    { "name": "침대", "w": 100, "d": 200, "h": null, "left": 0, "top": 0, "rotationDeg": 0 },
    { "name": "책상", "w": 120, "d": 60, "h": 72, "left": 220, "top": 20, "rotationDeg": 0 },
    { "name": "옷장", "w": 90, "d": 60, "h": null, "left": 130, "top": 220, "rotationDeg": 0 }
  ],
  "notes": [
    "침대는 왼쪽 벽과 위쪽 벽에 붙어 그려져 left 0, top 0으로 봄",
    "책상은 오른쪽 벽에 붙어 그려져 left = 340 - 120 = 220으로 봄",
    "옷장은 아래쪽 벽에 붙어 그려져 top = 280 - 60 = 220으로 봄",
    "옷장 아래 '←130→' 화살표는 왼쪽 벽에서 옷장 왼쪽 변까지로 해석함(화살표 끝이 벽에 닿지 않음)",
    "침대와 옷장의 높이는 적혀 있지 않음"
  ]
}
```
정답(그림을 만든 값)과 비교: 모든 값 일치. 남은 한계: 실제 굿노트 손글씨(필기체 숫자, 겹친 선)로는 아직 시험하지 않았다. 사용자 그림으로 다시 시험해야 한다.
